# Phase 4.1 Softmax 实验设计
单个连续 FP32 向量沿全长归一化。长度由运行时传入，受可分配显存限制，索引用 size_t。有限输入使用 exp(x−max)/sum(exp(x−max))。空向量返回空输出，和为零。另定义 +∞ 之间平分质量、全 −∞ 返回均匀分布，混合有限值与 −∞ 时后者概率为零。NaN 不在输入合约内。
1. 串行 GPU 三遍扫描建立 Naive 基线。独立 CPU 用 double 求稳定概率，逐元素检查绝对与相对混合容差、非负有限性，并以 double 验证概率和。每轮正确性检查前用 NaN 填充输出。
2. 单 Warp shuffle、单 Block 的 warp 分层归约、共享内存树归约、多 Block 分阶段归约分别验收。多阶段先并行求局部最大值，再合并最大值，求各块指数和，合并并归一化。统一使用默认 stream。
3. 增加寄存器分块与每线程多元素映射，对比缓存指数与重新读取。单 Kernel 融合 max、sum 和归一化，与分阶段版本同输入测量。
4. 测试空、单元素、Warp/Block 边缘、非整除尾部、长向量、重复最大值、常量及极端值。性能实验每配置预热，CUDA Events 测完整算子，CPU 时钟测 H2D 到 D2H。固定种子生成数据，两次独立进程改变顺序。保存中位数、样本标准差、线性 P95 和逻辑读写带宽 8N/time。此带宽按一次输入和一次输出折算。复用缓冲区并排除分配时间。
全部产物在 WhaleGPU-Phase41。每阶段编译、数值验收后再加入下一阶段算法。最终报告列出工具状态、精度与性能局限。
