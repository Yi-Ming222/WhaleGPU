# Phase 4.2 设计
对 R×H 的每行使用总体方差（除 H），计算 y=(x−mean)/sqrt(var+epsilon)*gamma+beta。输入、输出、gamma/beta 都为 FP32，统计量使用 double，以覆盖有限 FP32 输入平方可能溢出的情况。先把 float 输入转换为 double 再做减法；已在输入量化时消失的差异无法恢复。epsilon 为有限正 FP32 数。空行数或空特征维返回空输出。仿射支持关闭和逐特征参数。行主序和列主序贯穿输入输出，不在计时内转置。
阶段一实现串行行统计与独立 CPU double 两遍参考。阶段二对比 Block / Warp 两遍归约、逐行在线 Welford 与跨线程可合并 Welford。阶段三开发每线程四元素映射以及统计与仿射写回融合。长行跨步覆盖。每个阶段先完整验证，再扩展 Kernel。
正确性覆盖无元素、H=1、非整除、常量、随机、大偏移下相邻 FP32 值、极端正负值。逐元素检查有限性与绝对加相对误差；输出预填 NaN。稳定性记录均值、总体方差和输出的误差，区分两遍式、在线、可合并算法。
性能交叉行数、H、布局、epsilon、仿射开关。预热后测 CUDA Events 完整算子，E2E 包含 H2D、Kernel、D2H；两个独立进程改变配置顺序。逻辑带宽按一次输入、一次输出和启用时的一份 gamma/beta 计算。记录实际编译 Kernel 的静态资源。检查本机 profiler/sanitizer，数值验证与动态竞态检查各自报告。
