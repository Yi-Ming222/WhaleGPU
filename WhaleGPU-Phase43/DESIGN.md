# Phase 4.3 实施协议
三组实验按审计协议依次验收。主要形状 A=512³、B=262147、C=128×1024 行主序、仿射开启。每次完整算子使用原输入。两进程固定输入种子，变更顺序种子；使用 21 个配对轮次，每轮交替镜像顺序，10 次预热、10 次 Kernel 均摊。诊断项独立统计。E2E 从主机准备好的同精度输入开始，包括同步上传和下载，复用分配。主延迟不含分配，另测分配/释放。轮换缓冲区场景单列。
A scalar bias 为运行时 float。以原生产者的完整输出生成逐位 FMA 参照，同时验证 CPU double 理想结果。B 保留同一 FP32 概率和特殊值约定。C 保留 FP64 统计输出，C3 仅诊断。源文件适配由锚定原文件片段的生成步骤产生，生成物、原始头文件、命令、二进制及反汇编均保留。
