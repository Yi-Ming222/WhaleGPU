# Phase 3.6 实验设计
同级新目录只读引用 Phase 3.5 的 tensor_gemm 与 Phase 3 的参考函数。对 FP16 和 BF16 均交叉测试三个流程及三个 Kernel。CPU 流程从 pageable FP32 输入开始，现场转换、H2D、GEMM、D2H。GPU 流程上传 FP32，在设备转换后计算并回传。预转换流程从已准备好的主机低精度数组开始，包含 H2D、GEMM 和 D2H，前置转换不计入 E2E。所有流程复用分配，输出为 FP32。
基线使用每 Warp 一个 16×16×16 WMMA Tile。第二版按 2×2 个 Warp 组成 32×32 输出块，共享 A/B 加载。第三版使用两组输入 Tile，预取下一块，与当前块的 MMA 交叠。在地址对齐且连续有效时发出 16-byte cp.async，否则标量加载并补零。用两种规模的整块、非整除矩形、短 K、K=0 和多个随机种子验证。检查 CPU/GPU 转换位模式，量化参考与原 FP32 参考均用 double。
两个独立进程重新随机排列配置，每组预热，CUDA Events 单独测设备驻留 GEMM，steady_clock 测完整流程。报告每轮中位数、P95、原始样本、最大相对误差、RMSE 和绝对误差分箱。分母接近零时使用明确记录的下限。静态反汇编验证 HMMA 和异步加载。
